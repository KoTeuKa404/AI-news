# Відгук на вакансію

**Тема:** Відгук на вакансію «Спеціаліст з AI та автоматизації маркетингу»

Вітаю!

Зацікавила ваша вакансія спеціаліста з AI та автоматизації маркетингу. Мені близький саме практичний підхід 3M Agency: не просто використовувати ChatGPT, а будувати системи, які скорочують ручну роботу, зменшують кількість помилок і дають команді зрозумілий бізнес-результат.

Як приклад власної роботи можу показати локальний MVP AI-інфраструктури для маркетингового агентства:

1. **AI Content Intelligence та Telegram pipeline.** Система читає RSS-джерела, нормалізує та дедуплікує матеріали, завантажує повний текст статті, передає його в AI, перевіряє якість і мову, а потім відправляє готовий кандидат на Telegram-модерацію. Публікація захищена від повторів через atomic state transitions, а помилки мають контрольований recovery.

2. **Client Review Agent.** Окремий AI-агент вивчає історію правок і відхилень конкретного клієнта та до відправлення матеріалу прогнозує можливі зауваження до тексту. Агент працює через webhook, REST API та PostgreSQL-контекст і повертає перевірений structured JSON з ризиком, впевненістю та списком ймовірних правок.

У роботі використовую n8n, Python/FastAPI, PostgreSQL, SQLAlchemy, REST API, webhooks, Telegram Bot API та локальний AI Gateway. Мені комфортно самостійно розкласти бізнес-задачу на workflow, API, зберігання даних, retries, валідацію та моніторинг, а потім довести MVP до стабільної роботи.

Наступним логічним напрямом бачу автоматизацію Meta Ads і Google Ads: збір KPI, anomaly detection для CPL/CPA/CTR та бюджетів, AI-пояснення і повідомлення команді в Telegram.

Буду радий показати workflow наживо, пояснити архітектуру та обговорити, який внутрішній процес 3M Agency найкраще автоматизувати першим.
